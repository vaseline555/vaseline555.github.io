This project studies type 2 diabetes prediction using genome-wide polygenic risk scores and metabolic profiles.
It represents the application side of my portfolio, where modeling decisions need to be scientifically grounded and practically interpretable.

## Why It Matters

- The work connects machine learning with clinically relevant prediction tasks
- It demonstrates breadth beyond core federated learning methodology
- It reflects my interest in ML problems where optimization, data quality, and domain utility all matter
