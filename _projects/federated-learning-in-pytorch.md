This repository collects reusable PyTorch code for federated learning research, including baseline implementations and experiment-facing tooling for heterogeneous settings.

It reflects the part of my work that focuses on reproducibility and practical experimentation, not just algorithm design.

## Highlights

- Research-oriented codebase for federated learning experiments
- Useful as a reference implementation for rapid prototyping and benchmarking
- Designed around realistic training settings with heterogeneous clients
